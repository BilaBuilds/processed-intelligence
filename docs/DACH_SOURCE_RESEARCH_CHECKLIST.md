# DACH Source Research Checklist

## Required Fields

Every candidate source should be assessed for whether it can provide:

- title
- buyer
- country
- region
- deadline
- value
- cpv
- url
- source
- notice_id
- published_at
- description

## Assessment Columns

Use these checks for each source:

- Access mode: API, RSS, download, search-only, or manual portal.
- Authentication requirement: none, account, paid access, buyer/supplier login, or unknown.
- Terms/usage concern: allowed, unclear, restricted, robots-sensitive, redistribution-sensitive, or unknown.
- Scraper difficulty: low, medium, high, or avoid.
- Commercial usefulness: low, medium, high, or strategic.
